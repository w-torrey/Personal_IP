## Overview
The OSINT (Open Source Intelligence) Dashboard is a SaaS intelligence collection and monitoring tool that is generated by Google Dorks. The purpose of this project is to offer a dashboard-style tool to help corporate security teams keep continuous monitoring of public information related to executive protection, brand reputation, cyber threat intelligence, and other keyword assets of concern.

### What is a Google Dork
A Google Dork is a search query that uses Google's advanced search operators to narrow results down to very specific types of content or sources that a normal keyword search would miss. IndexPulse's dork engine combines several of these operators automatically when it builds a query for a target:
•      site: — restricts results to a specific domain or website (e.g. site:linkedin.com).
•      filetype: — restricts results to a specific file type, such as PDF or DOCX
•      intitle: / intext: — restricts results to pages with a keyword in the title or body text.
•      "quoted phrases" — forces an exact-match search
•      - (minus operator) — excludes results containing a given keyword
